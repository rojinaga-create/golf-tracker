# ⛳ Golf Tracker

A mobile-first golf scoring app built in React for our golf group in San Diego.

## Latest Version
**v23 - GolfTracker_v23_ArchiveFix.jsx**

## Features
- 📱 Mobile-first design optimized for iPhone Safari
- ⛳ 9 courses including San Diego CC, Coronado, Fairbanks Ranch, Torrey Pines, Tijuana CC, and Red Hawk Ridge (Castle Rock, CO)
- 🏌️ 11 game formats: Stroke, Stableford, Match Play, Skins, Nassau, Wolf, Scramble, Chapman, Four-Ball, and more
- 🎯 Quick tap score entry - gross score buttons + putt buttons (no keyboard needed!)
- 📊 Leaderboard with net scores, to-par, stableford points
- 💬 WhatsApp scorecard sharing (copy/paste)
- 📈 Excel export
- 💾 Auto-save to localStorage
- 📁 Round archive and history
